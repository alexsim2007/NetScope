## Следующие действия для выпуска

1. Создать репозиторий и отправить исходники по гайду. Сейчас в Git нет коммитов и remote; ничего не опубликовано.
2. Выбрать номер релиза, записать его скриптом и отправить тег. Текущие локальные пакеты имеют внутреннюю версию `0.0.0`; в гайде приведён пример `0.1.0`.
3. Дождаться нативной сборки обеих платформ на GitHub и проверить черновик. Подпись локального Mac в CI не переносится.
4. Проверить установку, WebView2, трей, возврат окна, уведомления и выход на настоящей Windows 10/11 x64. Кросс-сборка подтверждает получение пакета, запуск на Windows пока не проверен.
5. Проверить автозапуск, продолжение наблюдения при скрытом окне и реальную доставку уведомлений на целевых ОС. Alcove использует разрешённые системные уведомления; постоянный виджет скорости не реализован.
6. Завершить [расширенную проверку физического роутера](hardware-test.md), затем при необходимости настроить сертификаты распространения и нотарификацию. Подробный [протокол проверок](validation.md).

Эти ручные проверки и публикация требуют целевых систем и выбранного GitHub-репозитория. Незавершённой локальной компиляции или упаковки не осталось.
