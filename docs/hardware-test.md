# Manual D-Link DIR-815S S1 acceptance

Status: **basic authenticated native connection passed on macOS, 2026-11-01**. The installed app authenticated and discovered five devices; the user confirmed that devices are visible and updating. An earlier ad-hoc build failed with OS host-unreachable before authentication despite Local Network permission being enabled. After switching to a local Apple Development signature, native discovery succeeded. No password was supplied to the development tools. Counter directions, RSSI encoding, long-running nonce recovery and the complete procedure below are still unverified.

Use your own router and a trusted LAN. Do not scan other devices or change router settings. Keep a private local test report; publish only redacted results and synthetic screenshots.

1. Build and launch the native app. Complete setup with the explicitly chosen D-Link address and existing account. Grant macOS local-network permission if prompted. Confirm the wizard reports success only after Digest and both categories pass.
2. Compare the Wi-Fi client count, hostnames, MACs, multiple IP addresses, band, connection duration, SSID, link rate, raw RSSI, byte counters, and sleep flag against the router's ordinary client page. Confirm no duplicate devices for IPv4/IPv6 entries. Record firmware revision privately.
3. Try one intentionally incorrect password. Expect a readable authentication error, a cleared password field, bounded HTTP attempts, no demo fallback, and no continuous credential retries. Re-enter correct credentials.
4. Leave monitoring active across nonce expiration. Confirm ordinary authenticated polls increment nonce count, a stale challenge recovers, cookies (if required) survive, and collection does not overlap.
5. Put a known client to sleep or disconnect it. A neighbor-table `stale` record must remain stale. A client absent from both tables becomes offline only after the configured timeout. Observe one offline event, not one every poll. Reconnect it and confirm the local name/favorite survives.
6. Interrupt the computer's connection to the router. The network must become unknown/reconnecting; all clients must not generate offline events together. Check capped backoff and recovery. Repeat after Mac sleep/wake and a network change. Rate baselines must restart after interruption.
7. Compare counters while performing a known upload, then download, on one controlled client. Determine whether reported TX means router-to-client or client-to-router. **Do not relabel TX/RX as upload/download until measured.** Confirm counter resets and a Wi-Fi reassociation leave gaps rather than negative/spiked rates.
8. Exercise map selection, drag/zoom/fit/reset, filters, search by IPv6/MAC, editing names/types/icons, favorites, hiding and restoring from the Hidden filter, device events, all chart metrics, and all four time ranges. Confirm unreported fields remain unavailable.
9. Enable native notifications and relevant filters. Check discovery/offline/router recovery, favorite-only device filtering, and repeat suppression. Check tray pause/resume and menu navigation. Close to tray, wait through two polls, and reopen; history should continue. Use Quit and confirm the process exits.
10. Restart the app. Confirm both appearance themes, system-theme changes, native title bar, geometry and registry/preferences persist, live availability begins unknown, credentials are requested again, and reconnect resumes collection. Switch to Demo, then back to Live; histories must remain separate.
11. Test a Windows build on Windows 10/11: install, launch, WebView2 bootstrap if needed, display scaling at 100/150/200%, tray, notifications, close/quit, firewall behavior, restart, and uninstall.

Record platform, build hash, firmware, passed/failed step numbers, safe error codes, and any schema mismatch. Do not record passwords, Authorization headers, cookies, or production responses in the repository. If the real payload differs from the supplied shape, create a **synthetic minimal reproduction** and extend the parser tests before claiming compatibility.
