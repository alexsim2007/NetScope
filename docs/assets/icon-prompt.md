# Иконка NetScope

Создана встроенным инструментом imagegen. Исходник: `icon.png`. Стиль исходной иконки SwiftShield использован как ориентир; её пиксели не включены в приложение. PNG копируется в `src/assets/mark.png`, платформенные ICNS/ICO/PNG генерируются командой `npm run tauri icon -- docs/assets/icon.png`.

Промпт:

Create an original abstract three-dimensional sculptural emblem: three interlocking continuous toroidal loops arranged like a compact dynamic network knot, a balanced asymmetric orbit with clear negative space in its center. The user's SwiftShield icon is a visual style reference only: polished dark titanium and transparent glass interlocking sculpture on black. Make NetScope visually distinct: one smooth mirror-polished graphite/chrome loop, one luminous translucent cyan glass loop, and one deep cobalt glass loop. No etched patterns. Elegant restrained studio reflections, precise physical glass refraction and metal highlights, premium macOS desktop icon quality, strong readable silhouette at small size. Square composition, the sculpture centered and occupies about 78 percent of canvas, pure black background, no rounded-square outer tile, no words, no letters, no shield, no wifi symbol, no crosshair, no watermark. Deliver a single finished 1024x1024 icon.
